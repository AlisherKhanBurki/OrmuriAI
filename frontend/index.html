📐 Ormuri Generative Grammar Cheat Sheet

            
          

          

            

              
1. Split Ergativity Sentence Formula

              

                

                  Present / Future
                  Subject[DIR] + Object + VerbStem[Pres]-Agr[Subj] + {بُو /
                    سُو}
                

                

                  Verb agrees with the SUBJECT in person and number. Particle
                  بُو for present/habitual, سُو for
                  future.
                


                

                  Past Transitive
                  Agent-Clitic + Object[ABS] + VerbStem[Past]-Agr[Obj(Gender,
                    Number)]
                

                

                  Verb agrees with the OBJECT in gender and number. Agent is
                  marked by an enclitic hosted on the first constituent or
                  ال (al).

English

                

                  Ormuri (Bargista) is a critically endangered Eastern Iranian
                  heritage language native to Kaniguram, South Waziristan, with
                  only a few thousand fluent speakers remaining worldwide. This
                  AI generative engine was developed to document, preserve, and
                  revitalize this ancient linguistic heritage for future
                  generations.
                

                

                  Operating high-memory GPU cloud hosting, context caching
                  (866,060 tokens), and foundation model APIs requires recurring
                  infrastructure expenses. If you wish to support this noble
                  cultural mission, contributions are deeply appreciated and
                  directly sustain server uptime.
